Deterministic profile/type/group guidance is snapshotted from the read-only Python helpers by `expo/scripts/build-generation-guidance.py`; `expo/scripts/check-source-prompts.py` byte-compares the three default user prompts against Python. Their system prompts were also byte-compared locally. Canonical stage/level/language codes, Python default levels/material language, and separate teacher/student language fields now reach the server. Program-linked/student-personalized dynamic blocks, program skeleton/enrichment prompts, and provider fallback/normalization are not yet byte-equivalent.
